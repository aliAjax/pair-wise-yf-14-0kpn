# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

做一个给剧场灯光师使用的灯位与Cue表管理前端项目，可以维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和Cue触发顺序。页面需要有舞台平面灯位图、Cue列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 焦点时效复核

- 每盏灯确认焦点时记录**确认时间**与**走位坐标 (X, Y)**，确认后 **20 分钟内有效**（界面实时倒计时）。
- 执行 Cue 时按整组校验：任一灯具存在以下情况则**整组拒绝**，且原 Cue 顺序、舞台图、当前场景预览均不变化：
  - 确认已超过 20 分钟
  - 走位坐标为空
  - 确认时间早于最新走位调整（待复检）
  - 从未确认
- 单灯复检只更新该灯的确认记录，**不能替整组确认**。
- 登记走位调整后，旧确认记录保留并按过期处理，灯具进入“待复检”，在筛选与舞台图上标注。
- 灯具、确认记录、备注、当前场景与拒绝留痕保存在 localStorage，刷新后保留；过期状态按当前时间实时计算。

代码按业务拆分为三个文件：

| 文件 | 职责 |
| --- | --- |
| `src/focusStatus.ts` | 状态计算（时效、坐标、待复检判定、汇总） |
| `src/cueExecution.ts` | Cue 执行校验（整组拒绝规则） |
| `src/LightingConsole.tsx` | 界面（舞台图、Cue 列表、预览、筛选、单灯复检） |

`src/App.tsx` 只负责数据状态与 localStorage 持久化。
